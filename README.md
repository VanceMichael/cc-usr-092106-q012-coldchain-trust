# 伪冷链药品运输可信证明

描述药品冷链运输中箱体、批次、承运任务、交接人、传感器、校准版本、温度片段、开箱事件与质量结论之间的关系，并提供一个零依赖的参考后台逻辑：把这些证据重放成**可核验区间、超限、缺口、实际责任段**，并用只追加的哈希账本管理放行与撤销。

外观像冷链（泡沫箱加铝箔纸）不产生任何温度证据；没有读数的时间一律标成缺口，绝不用相邻读数补齐；晚到数据不能改写已发出的放行，只能追加撤销并沿批次谱系通知下游。

## 两层结构

- **证据层（只追加，不可变）**——`contracts/evidence.schema.json` 约束的证据包：
  `sensors` / `calibrations`（传感器身份与校准版本）、`containers`（含 `foam_wrapped` 伪装箱体）、
  `batches`、`tasks`（含跨时区路线）、`parties`、`events`（装箱/换箱/拼箱/拆分/交接/开箱/签收）、
  `temperature_segments`（携带 `uploaded_at` 与 `transmission: realtime | buffered_late`）、
  `quality_rules`（版本化，唯一缺口策略 `mark_noncompliant`）、`dispositions`（observe/quarantine/reject，
  必须引用规则版本与签署人）、`release_ledger`（哈希链）、`notifications`。
- **派生层（随时可重算）**——`src/` 下的纯函数：
  - `containment.js`：重放事件流，还原每个批次的实际容纳区间与责任段。换箱在边界封口、拼箱各自独立、
    拆分建立父子谱系，子批次责任链从拆分点续接；`signed_by: null` 的交接不补全责任。
  - `evaluation.js`：在任意 `as_of` 时刻只使用**当时已上传**的片段重算。相邻已知读点间隔不超过采样间隔
    才算可核验；更细粒度片段（如晚到导出的秒级缓存）在重叠区遮蔽压缩均值；读点缺失即 `sensor_offline`
    缺口，未装传感器为 `no_sensor`，证据未到为 `no_segment_yet`。
  - `ledger.js`：放行时把判定快照（可核验区间/缺口/超限/所用片段）固化进条目并计算 SHA-256 哈希链；
    撤销以新条目 `supersedes_entry_id` 指向旧条目，旧条目字节与哈希永不改变，`verifyLedger` 可验算。
  - `genealogy.js`：父子谱系、责任轨迹、撤销追查（为何撤销、晚到证据、受影响与仍待通知的下游批次）。
  - `scan.js`：接收方扫箱视图——可核验区间、超限、缺口、放行状态与"上游批次已撤销"的继承警示。
  - `time.js`：所有判定只用 UTC 瞬间；IANA 时区仅用于展示（`displayInTimeZone`）。

## 夹具剧情

`fixtures/evidence.json` 由 `scripts/generate-fixture.mjs` 生成（`npm run fixture`），是一条贯穿全部异常形态的虚构剧情：

1. **B1** 北京→法兰克福，跨时区（含 `+02:00` 本地写法）、中转开门、法兰克福换箱、与 **B2** 拼箱、
   到美因茨拆分为 **B1-A/B1-B** 分送药房与诊所。实时片段是 15 分钟压缩均值，把开门峰值平成 6.4°C，
   据此在 `REL-001` 放行。
2. 设备回库后导出的**秒级缓存片段次日才上传**，揭示约 37 分钟 >8°C 的真实超限 → 只追加 `REL-002`
   撤销，整批报废；沿谱系通知 B1-A（已确认）与 B1-B（仍待通知）。
3. **B4** 运输中传感器 05:00–09:00 掉线 → 缺口不插值，隔离、永不放行。
4. **B3** 泡沫箱加铝箔纸、无传感器、多轮无签署交接 → 接收方扫描直接判 `hold`/无证据拒收。

运行 `npm run report` 可看到接收方扫箱与质量负责人追查两个视图的实际文本输出。

## 本地校验

```bash
npm test      # node:test，14 项不变量测试
npm run report
```

测试固化的关键不变量：缺口区间内不存在任何作证样本；放行条目不引用晚于其时刻上传的片段；
同一旅程放行时合规、晚到片段到达后重算不合规；哈希链任何旧条目被改写都会被检出；
换箱/拼箱/拆分保留真实责任边界；未来规则版本不得溯及既往。所有数据均为虚构，不含真实个人信息或凭据。
